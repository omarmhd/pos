# مقارنة محاسبية: التحاليل المالية — الأصيل الذهبي مقابل نظامنا

**المرجع:** ملف "التحاليل المالية.pdf" (الأصيل الذهبي، الفصل 11).
**نظامنا:** `FinancialStatementService` (قائمة دخل + ميزانية عمومية) + الإقفال السنوي + تقارير المخزون.
**الخلاصة:** نظامك يغطي القوائم المالية والإقفال. الفجوة المحاسبية الأهم كانت **تقييم المخزون بقاعدة التكلفة أو صافي القيمة البيعية أيهما أقل (IAS 2)** — أُضيفت الآن.
**تاريخ الإعداد:** 2026-06-14

> **رموز:** ✅ موجود · 🔶 جزئي/بصيغة مختلفة · ⚠️ فجوة · ➕ أُضيف الآن.

---

## 1. تقييم المخزون (قيمة البضاعة الموجودة)

| طريقة الأصيل | عندنا |
|--------------|-------|
| معدل سعر الشراء (متوسط مرجّح) | ✅ التقييم الحالي بالتكلفة (AVCO عبر `CostPriceHistory`) |
| **السوق أو التكلفة أيهما أقل (LCM/NRV)** | ➕ **أُضيف: تقرير تقييم المخزون IAS 2** |
| السعر المختار (إحدى ٥ فئات أسعار) | 🔶 لدينا فئات أسعار (`ProductPrice`) |
| الوارد أولاً صادر أولاً (FIFO) | ⚠️ فجوة (يتطلب طبقات تكلفة) |
| الوارد أخراً صادر أولاً (LIFO) | ⚠️ فجوة (وغير مسموح بـ IFRS أصلاً) |
| التقييم لكل فرع/مخزن/قسم | ✅ تقرير المخزون per-branch/warehouse |
| بضاعة صادرة/واردة بإرساليات بلا فواتير | ⚠️ مرتبط بالإرساليات (فجوة سابقة) |

**ملاحظة محاسبية مهمة:** نظامك كان يقيّم المخزون **بالتكلفة فقط**. هذا لا يكفي لـ IAS 2 الذي يوجب القياس بـ**أقل من التكلفة وصافي القيمة البيعية** — وهو حرج للسوبرماركت (بضائع قرب الانتهاء/تالفة/راكدة تنخفض قيمتها البيعية تحت التكلفة).

## 4. ما أُضيف الآن ➕ — تقييم المخزون IAS 2

تقرير **"تقييم المخزون (IAS 2)"** في صفحة التقارير:
- لكل صنف: الكمية، تكلفة الوحدة، **صافي القيمة البيعية (NRV)** = سعر البيع المقدّر − تكاليف بيع تقديرية (٪ من `nrv_selling_cost_percent`)، **القيمة المعتمدة = الأقل**، و**هبوط القيمة الواجب** = (التكلفة − NRV) × الكمية حين تكون NRV أقل.
- إجماليات: قيمة التكلفة، صافي القيمة البيعية، القيمة المعتمدة، وإجمالي هبوط القيمة.
- فلتر "الأصناف التي تحتاج هبوط قيمة فقط".
- **قيد هبوط القيمة المقترح** (مدين مصروف هبوط قيمة المخزون / دائن مخصّص هبوط قيمة المخزون) — يُرحَّل يدويًا بعد المراجعة.

> لا migration — يعتمد على `cost_price`/`selling_price`/`quantity` الموجودة، ومفتاح إعداد اختياري `nrv_selling_cost_percent` (افتراضي 0).

## 5. ميزات إضافية نُفِّذت ➕ (كانت مقترحة، وأصبحت جاهزة)

| # | الميزة | الوصف |
|---|--------|-------|
| 1 | **تقييم FIFO** (`reports.fifo-valuation`) | تقييم المخزون المتبقي من أحدث طبقات الشراء (purchase_items) ومقارنته بـAVCO المعتمدة. تقرير تحليلي لا يغيّر محرّك التكلفة (يبقى AVCO حسب IAS 2 §25). |
| 2 | **الميزانية بأي عملة** (الميزانية العمومية) | اختيار "عملة العرض" يحوّل كل أرقام الميزانية بسعر الصرف عرضيًا (مثل "عملة الميزانية" في الأصيل). |
| 3 | **حاسبة تكلفة الاستيراد** (`reports.landed-cost`) | إدخال الكمية/السعر/الصرف/الشحن/الجمارك/مصاريف → تكلفة الوحدة الكلية (Landed) + سعر بيع مقترح حسب الهامش. |
| 4 | **الرسوم التحليلية** (`reports.analytics`) | رسوم Chart.js لاتجاه المبيعات والمشتريات وصافي الفرق آخر ١٢ شهرًا. |

> الأربعة بلا migration (للقراءة فقط أو حساب في المتصفح)، عدا الميزانية متعددة العملات فهي تحويل عرضي على التقرير القائم.
