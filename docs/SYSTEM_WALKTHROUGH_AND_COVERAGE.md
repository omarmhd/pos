# فحص شامل صفحة-صفحة + تغطية احتياجات المحلات التجارية

**التاريخ:** 2026-06-15
**النطاق:** فحص ساكن منهجي لكل واجهات النظام من السايدبار + جرد تغطية المتاجر.

> **حدود المنهجية:** فحص ساكن للكود (لا يمكن تشغيل النظام/النقر فعليًا في هذه البيئة). يصطاد **أصناف الأخطاء الهيكلية** التي تُعطّل الصفحات، لا أخطاء البيانات اللحظية (تُكشف بالتشغيل + اختبارات CI).

---

## 1. نتائج صيد الأخطاء الهيكلية (سُوِّيت)

| صنف الخطأ | الوصف | النتيجة |
|-----------|-------|---------|
| `@push('scripts')` ميت | اللاي-آوت يستخدم `@yield('scripts')` فلا يُعرض `@push` | ✅ أُصلحت كلها (ar/ap-aging + الدليل) |
| تهيئة DataTable مزدوجة | جدول يحمل `dt-table` + تهيئة يدوية → "Cannot reinitialise" | ✅ الشيكات فقط — أُصلح |
| partial مفقود | `@include('components.alerts')` غير موجود → استثناء | ✅ أُنشئ |
| متغيّرات فلتر الفروع | `branch-filter` في 27 صفحة | ✅ المكوّن **دفاعي** (`isset`) — لا يتعطّل |
| روابط السايدبار | اسم مسار خاطئ يكسر كل صفحة | ✅ كلها صحيحة (النظام يتصفّح) |

**النتيجة:** لم يتبقَّ أي صنف خطأ هيكلي معروف يُعطّل صفحة. التحقق الديناميكي النهائي يتم بتشغيل النظام + اختبارات CI التي أُضيفت.

## 2. جرد الصفحات (من السايدبار) — ~50 شاشة

### نقطة البيع والمبيعات
نقطة البيع · الورديات النقدية · عروض الأسعار · أوامر البيع · فواتير البيع · مرتجعات البيع · **فواتير إيراد الخدمات** · العملاء والذمم المدينة.

### المشتريات
الموردون · أوامر الشراء · فواتير الشراء · مرتجعات الشراء · فواتير المصاريف · **الإقرارات الجمركية**.

### المخزون
المنتجات (**أصناف / منتجات مصنّعة منفصلة الآن**) · الفئات · تحويلات المخزون · تسويات المخزون · جلسات الجرد · التصنيع/التجميع.

### السندات والشيكات
سندات القبض · سندات الصرف · السندات المجمّعة · الشيكات (دورة حياة كاملة + تجيير + إعادة إيداع).

### المحاسبة
لوحة المحاسبة · القيود اليومية · دفتر الأستاذ · الأصول الثابتة + فئاتها · دليل الحسابات · الفترات المحاسبية · قيود التصحيح/العكس · التحويلات بين الفروع · مراكز التكلفة · الموازنات.

### الموارد البشرية
الموظفون · الورديات · مسير الرواتب · السلف · الإجازات · نهاية الخدمة (EOSB).

### التقارير
مركز التقارير (مبيعات/مشتريات/أرباح/مخزون/أكثر مبيعًا/تقادم AR+AP/**تقييم IAS 2/FIFO/تكلفة استيراد/تحليلات/خصم مصدر/تنبيهات مخزون/راكد/تغيّر تكلفة**) · كشوف الإيرادات والمصروفات (إقرار ض.ق.م الدوري) · القوائم المالية (دخل + ميزانية بأي عملة).

### الإدارة والإعدادات
المستخدمون · الأدوار والصلاحيات · الفروع · المخازن · نقاط البيع · قوائم الأسعار (بيع/شراء) · العملات · سجل التدقيق · النسخ الاحتياطي.

| الحاجة | الحالة |

| المخزون (أصناف، فئات، تعدد وحدات، تعدد مخازن، حدود دنيا/قصوى/إعادة طلب، لوط/صلاحية، تسويات، جرد دوري، تحويلات) | ✅ |

## 4. الخلاصة

**النظام يغطي جوهر احتياجات المتجر التجاري (POS + مخزون + مشتريات + عملاء + محاسبة كاملة + HR + تقارير) تغطيةً ممتازة وأقوى من كثير من الأنظمة المنافسة** (ترحيل آلي، تعدد فروع، تصنيع، إقرار ض.ق.م دوري، تقييم IAS 2). الفجوات المتبقية هي أساسًا **مزايا تسويق التجزئة** (الولاء، الحملات، بطاقات الهدايا) و**مستندات/وحدات تشغيلية** (الإرساليات، RFQ، تعدد الشركات، الإشعارات).

**التوصية:** إن كان النشاط تجزئة تنافسية، أولوية الفجوات: (1) الولاء/النقاط، (2) محرّك العروض/الحملات، (3) الإشعارات. وإن كان متعدد الكيانات: تعدد الشركات ضمن هجرة Filament.
